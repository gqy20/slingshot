# S01E05 分镜：最短的路为什么不一定最快？

## 制作约束

- 目标时长：210 秒（3 分 30 秒）；
- 硬上限：240 秒（4 分钟）；
- 当前状态：40 秒纵向原型已通过科学与画面审查，正式分镜待逐镜实现；
- 物理模型：同起点、同终点、均匀重力场、无摩擦滑动质点；
- 核心结论：路径长度只描述“走多远”，到达时间取决于整条路径上的速度分布；
- 叙事边界：等时性只作为结尾问题，不在本集展开第二套完整证明。

## 五阶段时间预算

| 阶段 | 区间 | 时长 | 任务 |
| --- | --- | ---: | --- |
| QUESTION | 0:00–0:25 | 25 s | 建立“直线最短，所以应该最快”的下注 |
| EXPLAIN | 0:25–1:15 | 50 s | 从高度差、速度到累计时间建立解释工具 |
| SETUP | 1:15–1:45 | 30 s | 明确公平条件并介绍三条轨道 |
| FLIGHT | 1:45–2:45 | 60 s | 真实比例比赛、终点慢放与到达锁定 |
| COMPARE | 2:45–3:30 | 45 s | 路程—时间对照、摆线生成、模型边界与下集问题 |

总时长：`25 + 50 + 30 + 60 + 45 = 210 s`。

## Episode 配置映射

正式实现时，`story` 建议使用：

```json
{
  "question_sec": 25.0,
  "explain_sec": 50.0,
  "setup_sec": 30.0,
  "flight_sec": 60.0,
  "compare_sec": 45.0
}
```

Beat 可以保持显式时间线，阶段边界必须分别落在 `25 / 75 / 105 / 165 / 210` 秒。当前 40 秒 Episode JSON 继续作为可运行原型，直到上述镜头至少完成无声预览；不要用旧的五阶段画面机械拉伸填满 210 秒。

## 实现顺序

1. 扩展 Track RunRecord：累计距离、累计时间、高度差与分段时间贡献；
2. 实现 `distance-is-not-time`、`energy-drop`、`time-integral` 三个解释镜头；
3. 实现真实比赛、终点慢放和落后毫秒数；
4. 实现路径长度—到达时间双列结果；
5. 实现摆线生成动画与模型边界卡；
6. 把本分镜迁移进 Episode JSON，渲染 1080p 无声样片；
7. 画面锁定后再写讲稿、生成配音和字幕。

## 进入配音前的验收标准

- 总时长必须为 210 秒，且任何调整不得超过 240 秒；
- 观众不看结果表也能识别摆线首先到达；
- 42 ms 的摆线—圆弧差异必须通过带时间标记的慢放诚实呈现；
- 至少一镜直接展示“更长路径”与“更短时间”同时成立；
- `v = √(2gy)` 与 `T = ∫ ds / v` 都必须由运动画面引出；
- 明确标注无摩擦滑动质点模型，不把真实滚动物体直接等同于模拟；
- 新增镜头必须进入视觉回归，且密集帧审查无文本或主体重叠。
