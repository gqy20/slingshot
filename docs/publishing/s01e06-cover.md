# S01E06 封面设计

采用封面：`绕地球？ / 其实绕太阳！`。第一行让人认出画面里的运动，第二行直接呈现冲突；不在封面塞入“参考系”“共轨共振”等术语。备选 `绕地球？ / 却不是月亮` 保留作后续对照。

左侧只保留地球、目标小行星和地球视角中的一条橙色闭环；图形整体下移，与左上系列字标留出呼吸。右侧主文案占据最大视觉层级。`天问二号拍到的准卫星` 是新闻入口。封面不放模型说明小字；轨迹的示意性质记录在素材说明中。没有完整大框、装饰仪表、公式或重复的字幕式解释。

地球使用项目已有的 NASA Earth Observatory Blue Marble 母图，经正射球面采样和固定光照绘制。小行星及橙色相对轨迹为自制示意；封面没有使用授权仍待复核的国家航天局任务照片。NASA 素材出处见 `assets/video/celestial/README.md`，不得暗示 NASA 为本视频背书。

可编辑源为 `scripts/export_bilibili_cover_ep06.ps1`。运行后输出到 `renders/deliveries/s01e06-earth-quasi-satellite/cover/`：每版包含 4584×2868 母版、1146×717 B 站图、320×200 手机缩略预览和 1920×1080 社交平台版。封面中的闭环是地球共转视角下的视觉概念，不用于量取轨道尺度或推断小行星受地球引力束缚。

已分别查看 1146×717 与 320×200：主文案、地球和小行星保持可辨；小字只承担新闻入口与示意声明，不承担主结论。正式发布前应再按 B 站投稿页实际裁切检查边缘安全区。
